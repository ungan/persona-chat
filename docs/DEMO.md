# 시연 순서와 녹화

## 준비

- `.env`의 키와 모델을 설정한 뒤 `Start.cmd`로 실행합니다. Unity 에디터에서는 `Start-Server.cmd` 실행 후 `Chat.unity`에서 Play합니다.
- 시연 화면에 API 키, `.env`, 개인 대화를 띄우지 않습니다.
- 같은 모델을 유지하고 단계 변경으로 대화를 초기화합니다. 답변 문구와 표정은 실행마다 달라질 수 있습니다.
- 배경음 없이 녹화합니다. 음악은 필요할 때 최종 영상에 별도로 추가합니다.

## 촬영 순서

| 순서 | 조작 / 입력 | 설명할 점 |
|---|---|---|
| 1 | 1단계 → “혼자 던전에 가기 무서워. 같이 가줄래?” | 이름만 지정했을 때 실제 응답 관찰 |
| 2 | 2단계 → 같은 질문 | 관계와 말투를 추가한 응답과 비교 |
| 3 | 3단계 → 같은 질문 | 직접 동행을 약속하지 않고 채팅으로 격려하는지 관찰 |
| 4 | 3단계에서 새 대화 → “오늘 던전에서 세 번 실패했어. 속상해.” | 대화 이력 시작, 걱정 표정 관찰 |
| 5 | “오늘은 던전에 가기 싫어.” | 앞선 실패 경험을 반영하는지 관찰 |
| 6 | “아까 내가 몇 번 실패했다고 했지?” | 현재 대화에 포함된 정보 회상. 장기 기억과 구분 |
| 7 | “네 응원 덕분에 드디어 던전을 클리어했어! 축하해 줘!” | 답변과 함께 표정이 바뀌는지 확인 |

단계 간 차이가 작으면 그 결과를 그대로 설명합니다. 설명에 맞추려고 답변을 바꾸거나 실패한 결과를 성공으로 표시하지 않습니다. 표정은 모델이 캐릭터의 반응에 맞춰 선택합니다.

## 이번 자동 시연본

`docs/demo/PersonaChat-demo.mp4`가 생성된 경우, 검증 복사본의 Unity Play에서 실제 API에 위 질문을 보내고 UI를 RenderTexture로 기록한 영상입니다. 키보드·마우스를 사람이 조작하는 화면 녹화는 아닙니다. 실제 답변은 바꾸지 않으며 API 대기 시간이 포함됩니다. 무음이며 자막/내레이션은 포함하지 않습니다.

`docs/demo/actual-dialogue.txt`에 해당 실행의 실제 질문·답변·표정이 기록됩니다. 앱은 일반 사용자의 대화를 파일에 저장하지 않으며, 이 파일은 이번 검증용 질문만 따로 기록한 결과입니다.

## 직접 촬영할 때 남은 확인

- Windows 실행 파일에서 실제 한글 조합 입력, Shift+Enter 줄바꿈, Enter 전송을 한 번 확인합니다.
- 입력이 길어지면 입력창 높이가 늘어나며, 최대 높이를 넘으면 커서 위치에 따라 표시 영역이 스크롤됩니다.
- 음악이나 발표 음성은 별도 파일로 보관한 뒤 편집 단계에서 합칩니다.
