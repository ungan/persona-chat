Persona Chat — 처음 사용하는 분을 위한 안내

코드와 설명: https://github.com/ungan/persona-chat
Windows 실행 ZIP: https://github.com/ungan/persona-chat/releases

이 앱은 캐릭터와 대화하는 Windows용 채팅 앱입니다.
실행용 ZIP에는 Unity 앱과 Java 서버가 함께 들어 있습니다.
사용만 할 때는 Unity나 Java를 따로 설치할 필요가 없습니다.

준비물: Windows 10/11 64비트 PC, 인터넷, 본인의 OpenAI API 키
API 사용 요금은 입력한 키의 계정에 발생합니다.

1. 실행용 ZIP 전체를 풀기

   공유 묶음을 받았다면 01_PersonaChat_실행용.zip을 먼저 풀어 주세요.
   ZIP 안에서 바로 실행하지 말고, 문서 폴더 등 파일을 저장할 수 있는
   폴더에 전체 압축을 풀어 주세요.
   채팅 시작.cmd, .env, release, runtime 등의 파일·폴더를 함께 둡니다.
   실행 파일만 따로 꺼내면 작동하지 않습니다.

2. .env에 본인 키 입력하기

   채팅 시작.cmd와 같은 폴더에 있는 .env 파일을 메모장으로 엽니다.
   연결 프로그램을 물어보면 메모장을 선택합니다.
   아래 두 줄을 확인하고, 예제 키를 본인 키로 바꿉니다.

   LLM_API_KEY=본인의_API_키
   LLM_MODEL=gpt-4.1-mini

   '본인의_API_키'라는 글자를 그대로 넣는 것이 아니라 실제 키를 넣습니다.
   처음에는 모델 이름과 다른 설정은 그대로 두는 것을 권장합니다.
   Ctrl+S로 저장하고 메모장을 닫습니다.
   파일 이름을 .env.txt로 바꾸지 마세요.
   .env가 없으면 채팅 시작.cmd를 한 번 실행해 예제 파일을 만들 수 있습니다.

3. 채팅 시작하기

   채팅 시작.cmd를 더블클릭합니다.
   서버를 준비하는 동안 잠시 기다리면 채팅 창이 자동으로 열립니다.
   '연결됨' 표시를 확인한 뒤 메시지를 입력합니다.

   Enter              메시지 전송
   Shift+Enter        줄바꿈
   1단계 / 2단계 / 3단계  캐릭터 설정 전환 (이전 대화 초기화)
   새 대화             현재 단계에서 대화 초기화

   긴 입력은 입력창이 늘어나며, 최대 높이를 넘으면 커서를 따라 스크롤됩니다.
   대화는 종료하거나 초기화하면 사라집니다.

4. 종료하기

   채팅 창의 X 버튼을 누르면 앱과 함께 시작한 서버도 종료됩니다.
   서버가 남아 있다면 같은 폴더의 Stop.cmd를 실행합니다.
   .env나 프롬프트를 수정했다면 앱과 서버를 종료한 뒤 다시 실행합니다.

잘 안 될 때

   - 키 설정 안내가 나옴:
     .env의 your-api-key-here를 실제 키로 바꾸고 저장했는지 확인합니다.
   - 앱은 열리지만 대화 요청이 실패함:
     키의 사용 가능 상태, 모델 접근 권한, API 사용 한도와 인터넷을 확인합니다.
     '연결됨'은 로컬 서버 연결 표시이며 실제 API 키 검증 완료를 뜻하지 않습니다.
   - 이미 실행 중이라는 안내가 나옴:
     기존 채팅 창을 사용합니다. 다시 열려면 먼저 기존 창을 닫습니다.
   - 에디터용 서버가 이미 켜져 있음:
     Stop.cmd로 서버를 종료한 뒤 채팅 시작.cmd를 실행합니다.
   - 포트가 사용 중이라는 안내가 나옴:
     다른 Persona Chat을 종료하거나 .env의 CHAT_PORT를 비어 있는 값으로 바꿉니다.
   - 실행 파일이 없다는 안내가 나옴:
     소스 ZIP 대신 실행용 ZIP을 받았는지, 전체 압축을 풀었는지 확인합니다.

캐릭터를 바꾸고 싶다면

   prompts 폴더의 stage1.txt / stage2.txt / stage3.txt: 캐릭터 설정
   character 폴더의 character.json: 이름과 표정 이미지 경로
   자세한 설정·이미지 교체 방법은 README.md를 참고하세요.

공유 묶음의 구성

   00_먼저읽기.txt              이 안내
   01_PersonaChat_실행용.zip    바로 실행할 Windows 앱과 서버
   02_PersonaChat_소스.zip      Unity 클라이언트 + Java 서버 소스

   소스 ZIP은 코드를 읽거나 수정할 사람을 위한 별도 자료입니다.
   소스를 수정·빌드할 때 필요한 도구와 순서는 소스의 README.md에 있습니다.
   단순히 채팅을 사용할 때는 소스 ZIP을 풀지 않아도 됩니다.

API 키는 채팅으로 보내거나 화면 녹화에 담지 마세요.
키를 입력한 .env와 .run 폴더는 다른 사람에게 공유하지 마세요.
배포받은 각 사용자가 자신의 키를 입력해서 사용합니다.
